# Cinematic Camera Trainer

1단계 실제 WebGL 3D 촬영 시뮬레이터. Three.js 0.180.0을 로컬 포함합니다. 유료 API나 사용자 촬영·마이크 입력을 사용하지 않습니다.

## 기능
- 3D 해변, 애니메이션 대체 인물, 깊이감 확인용 전경과 배경
- 실제 카메라 프리뷰와 촬영장 뷰
- Dolly 시작/종료 좌표 편집, Orbit 반경·회전각·높이 편집
- 재생, 일시정지, 타임라인, 시작/종료 구도
- 24–70mm 풀프레임 화각, 추적/수동 방향
- 터치 이동, 두 손가락 핀치, 탐색/편집 모드
- 로컬 저장, JSON 백업·복원, 오프라인 캐시

## 실행
정적 HTTP 서버로 dist/를 제공합니다. file:// 대신 localhost 또는 HTTPS로 접속하세요. 테스트: `node --test tests/motion.test.mjs`. GitHub Pages는 Actions 배포를 선택하면 main 푸시 후 dist/를 자동 배포합니다.

## 검증
2026-10-14 KST, Windows Chrome headless에서 실제 WebGL draw call과 화면 픽셀 변화, 사용자 종료점 편집, Dolly/Orbit, 재생/정지, 저장/복원, JSON, 터치 드래그·핀치, 1024×768/390px 레이아웃, 오프라인 재실행을 확인했습니다. 순수 경로·화각·입력 검증 테스트 4개 통과.

iPad Safari 실기기와 홈 화면 설치는 미검증입니다. 데스크톱 터치 에뮬레이션을 실기기 테스트로 간주하지 않습니다.

## 범위와 근사
- 학습 상황은 1개이며 채점/다수 문제는 2단계입니다.
- Orbit은 원점의 피사체 주변에서 시작 반경을 유지합니다. 종료점 X/Z는 회전각으로 변환됩니다.
- 센서 너비 36mm, 16:9 크롭의 투영 화각입니다. 깊이감과 시점은 실시간 3D지만 심도·노출·모션 블러·렌즈 왜곡·짐벌 물리는 재현하지 않습니다.
- 문제 학습 이력은 아직 없으며 촬영 설계 1개를 브라우저에 저장합니다. 브라우저 데이터 삭제 전 JSON 백업하세요.
